eSSL / ZKTeco Terminal Setup Guide

Follow these steps on the physical biometric terminal:

  1. Press Menu / OK on the device.
  2. Navigate to Comm. → ADMS / Cloud Server.
  3. Enable Domain Name or enter IP.
  4. Set Server Address: connect.nexuswave.in (Port 80/443).
  5. Reboot terminal. The status will turn to Push Active immediately.
✓ Push Active: Terminal will push live check-in timestamps in <1 second.
